# Meenakshi Ojha – Frontend Portfolio

Personal portfolio website showcasing my experience, architecture case studies, and downloadable ATS-friendly resume.

## 🌐 Live
[meenakshiojha.com](https://meenakshiojha.com) (also deployed on Vercel)

## 👩‍💻 About Me
Senior Frontend Engineer with six years of experience building scalable banking applications, component libraries, and microfrontend architectures using React, TypeScript, and modern tooling. I focus on performance, accessibility, test-driven development, and high-quality UI architecture.

## 🚀 Features
- Experience Timeline with project-wise impact
- Architecture-focused case studies (anonymized enterprise work)
- Downloadable ATS-friendly one-page resume (PDF)
- Dark / Light theme toggle
- Responsive design with Material UI
- SEO-ready Next.js App Router setup

## 🛠 Tech Stack
- Next.js (App Router)
- React + TypeScript
- Material UI (MUI)
- @react-pdf/renderer for resume generation
- Vercel (deployment)

## 📂 Key Sections
- `/` – Home
- `/experience` – Professional timeline
- `/projects` – Case-study style architecture highlights
- `/resume` – Web view + downloadable PDF
- `/contact` – Contact details

## 📄 Resume
The resume is generated using `@react-pdf/renderer` and available for direct download from the site.

## 🧠 Case Study Philosophy
Instead of toy side projects, this portfolio highlights real-world enterprise initiatives (anonymized) focusing on:
- Problem → Architecture → Impact
- Scalability and team-level contributions
- Quality, testing, and performance improvements

## ⚙️ Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## 📦 Scripts
- `npm run dev` – Start development server
- `npm run build` – Build for production
- `npm start` – Start production server
- `npm run lint` – Run ESLint
